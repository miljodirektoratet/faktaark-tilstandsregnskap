# Faktaark for tilstandsregnskap
Faktaark med informasjon om indikatorene i nasjonalt tilstandsregnskap. 

## Legg inn nytt ark
1. Legg pdf-filen i assets/pdf, feks assets/pdf/faktaark1.pdf
2. Kopier testark.md til et nytt ark og navngi det som pdf-filen, feks faktaark1.md
3. Endre title, permalink og filstier i .md-filen til det som passer til det nye faktaarket. Commit changes... skal nå starte deployment som oppdaterer nettsiden.
4. Sjekk at det ser ok ut på nettsiden.
